# Fuentes de los logos

Descargados el **18 oct 2026**. Todos son archivos oficiales: no se dibujó ni se modificó ninguno.
Convención: `<slug>.<ext>` para fondo claro y `<slug>-dark-bg.<ext>` para fondo oscuro (el deck).
Los avatares de GitHub (`*-github-avatar.*`) son respaldo: imagen cuadrada, a veces con fondo propio.

Antes de usar un logo en el deck, revisa la columna de condiciones. En una charla, el uso nominativo
(mostrar el logo para identificar el producto del que se habla, sin sugerir patrocinio) es lo habitual,
pero Google y Meta piden aprobación explícita para cualquier uso de su logo.
