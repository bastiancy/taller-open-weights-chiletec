# Presentación

- `dist/index.html` — el deck listo para presentar.
- `deck.src.html` — fuente editable. Compilar con `python3 slides/build.py`.
- `shoot.py` — capturas de revisión: `python3 slides/shoot.py 4:1 8:5` (requiere Playwright).

Navegación: flechas o espacio, **F** pantalla completa, `#n` en la URL para ir a la diapositiva n.
